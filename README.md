# Swole Cat

A private, local-first workout tracker and progressive-overload app.

## Data
Workout history is stored locally in the installed browser/PWA on each device. The GitHub repository contains app code only, not workout history.

## Install
Once GitHub Pages is enabled, open the Pages URL in Chrome on Android and choose **Install app** or **Add to Home screen**.

## Updating
Changes committed to `main` automatically redeploy through the GitHub Pages workflow.
